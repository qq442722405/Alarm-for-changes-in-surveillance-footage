# 监控回放智能监控

Windows 桌面程序，用于快速检查监控录像中指定区域是否发生变化、是否出现人员。

## 主要功能

- 打开 MP4/AVI/MOV/MKV 等录像
- 鼠标框选多个监控区域
- 每个区域独立设置：
  - 变化检测开关
  - 人员检测开关
  - 灵敏度
  - 最小变化面积
  - 连续触发帧数
  - 冷却时间
- 录像播放/暂停、进度条、逐帧前进后退、跳过无变化片段
- 变化时自动暂停/报警/截图
- 发现人员时报警/截图
- 报警记录列表，可点击记录跳到对应时间
- 支持导出事件 CSV
- 支持保存/加载区域配置
- 支持报警声音测试、静音
- 支持全屏预览
- YOLO 人员识别采用 ultralytics，首次运行会自动下载轻量模型
- 没有人员模型时，变化检测仍可独立工作
- GitHub Actions 自动打包 Windows EXE

## 本地运行

Python 3.10/3.11 推荐。

```bash
pip install -r requirements.txt
python main.py
```

## GitHub 在线打包

把整个工程上传到 GitHub，Actions 会自动运行 `.github/workflows/build.yml`。

生成的文件：
`监控回放智能监控-Windows.zip`

## 使用建议

1. 打开录像。
2. 点击“框选区域”。
3. 在画面上拖动鼠标画出需要检查的区域，可连续添加多个区域。
4. 在右侧修改每个区域灵敏度。
5. 打开“人员检测”即可检测画面中的人。
6. 点击“开始智能监控”。
7. 软件默认发现事件后暂停，方便你直接查看现场；可在设置中关闭自动暂停。

### 灵敏度

0-100，数值越高越容易触发。

建议：
- 室内固定摄像头：30-50
- 室外：45-70
- 夜间：55-80

程序同时使用像素差、面积比例、形态学去噪和连续帧确认，减少单帧噪点造成的误报警。

### 注意

人员识别依赖 YOLO 模型。首次执行人员检测时需要网络下载模型；下载后的模型会缓存到用户目录。
