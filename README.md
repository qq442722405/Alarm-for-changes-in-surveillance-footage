# 屏幕监控智能报警

Windows 屏幕区域监控工具。程序直接抓取实际屏幕，不导入或打开视频文件。

## 本版主要优化

- 修复“画面变化不报警”的检测逻辑。
- 使用“相邻帧 + 当前基准帧”双重变化检测。
- 灵敏度 0～100 可调。
- 最小变化面积默认 0.8%，可进一步降低到 0.05%。
- 连续确认默认 2 帧，可设为 1 帧。
- 增加“重置检测基准”。
- 自动保存报警截图。
- 支持多个四点监控区域。
- 框选时保持真实屏幕画面可见。
- “显示框选区域”可随时开关。
- 报警区域边框变红，并显示实时变化百分比。
- 独立的开始、停止、暂停、继续状态，不再互相冲突。
- 深色卡片式界面。
- 使用 app.ico 作为程序图标。
- 删除 __pycache__ 等无用工程文件。
- GitHub Actions 仅保留 workflow_dispatch 手动打包。

## 解决画面变化不报警的推荐设置

第一次测试建议：

- 灵敏度：80～90%
- 最小变化面积：0.3～0.8%
- 连续确认：1～2 帧
- 报警冷却：5～10 秒

如果仍然不报警：

1. 点击“重置检测基准”。
2. 确认“启用该区域”和“检测画面变化”均已勾选。
3. 将灵敏度调到 90～100%。
4. 将最小变化面积降低到 0.1～0.3%。
5. 连续确认设置为 1 帧。

## 本地运行

```bash
pip install -r requirements.txt
python main.py
```

## 本地打包

双击 `build.bat`。

生成：

`dist/屏幕监控智能报警.exe`

## GitHub 手动打包

上传整个工程后进入：

Actions → Windows EXE → Run workflow

不会因为 push 自动打包。

## 数据目录

程序配置和报警截图位于：

`%USERPROFILE%\\.screen_monitor_ai`

其中 `regions.json` 是区域配置，`snapshots` 是报警截图。
