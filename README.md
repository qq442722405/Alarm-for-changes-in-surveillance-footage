# 监控变化报警

Windows 屏幕区域智能监控工具。程序直接监控实际屏幕，不打开、不导入视频文件。

## 本版重点优化

### 画面变化检测
- 相邻帧 + 自适应背景双重检测。
- 小碎片过滤、形态学去噪、连通域大块过滤。
- 对“草被风吹、树叶晃动、压缩噪点”等大量细小变化更不敏感。
- 实时变化数值使用平滑算法，显示不会疯狂跳动。
- 变化触发面积最低 0.05%，可以检测更小的变化。
- 增加“有效大块变化”阈值，用于过滤草叶等碎片。

### 人员检测
- 使用 YOLO 人员类别检测。
- 人员检测独立于画面变化检测。
- 人进入后即使站着不动，也可以报警。
- 人员框只需与四点监控区域有约 8% 交集即可认为进入，适合半身进入场景。
- 支持人员置信度、连续确认次数、检测间隔设置。
- 首次启用人员检测时可能需要联网下载 yolo11n.pt。

### 框选
- 四点框选。
- 框选时保留实际屏幕画面，只加轻微透明遮罩。
- 已框选区域可以显示/隐藏。
- 监控区域不会因为框线颜色变化导致自身误报。

### 其他
- 多监控区域。
- 每个区域独立参数。
- 报警截图。
- 报警冷却。
- 报警后自动暂停。
- 事件 CSV 导出。
- 配置自动保存。
- Windows ICO 图标。
- GitHub Actions 仅手动触发：workflow_dispatch。

## GitHub 打包

上传整个工程后：

Actions → Windows EXE → Run workflow

不会因为 Push 自动打包。

## 本地打包

双击 `build.bat`。

生成：`dist/监控变化报警.exe`

## 数据目录

`%USERPROFILE%\\.screen_monitor_ai`

包含区域配置和报警截图。


### 人员检测测试
在“画面检测抗干扰参数”中打开 **启用人员检测（YOLO，推荐测试）**。该开关独立于画面变化检测；即使人物动作很慢、穿黑色衣服导致像素变化不明显，也会尝试通过人员目标检测报警。默认置信度 0.20，可在识别不到人时逐步降低到 0.10～0.15 测试。模型 `yolo11n.pt` 已随工程一起打包，正常情况下无需首次联网下载。
