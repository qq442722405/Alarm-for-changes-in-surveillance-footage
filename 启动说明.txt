屏幕监控智能报警

使用：
1. 先打开监控回放网页或软件。
2. 点击“＋ 四点框选区域”。
3. 在真实屏幕上依次点击需要监控区域的四个角。
4. 框选完成后，可以继续添加其他区域。
5. 选中区域，调整灵敏度、最小变化面积、连续确认等参数。
6. 点击“开始监控”。

如果画面变化没有报警：
- 灵敏度调到 80～100%。
- 最小变化面积调到 0.1～0.8%。
- 连续确认调为 1～2 帧。
- 点击“重置检测基准”。

“显示框选区域”只控制屏幕上的框线显示，不影响检测。

GitHub Actions 采用手动触发：
Actions → Windows EXE → Run workflow
